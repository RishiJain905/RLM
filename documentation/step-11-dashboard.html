Overview

The untrained model on the 64-task selection set

Every arm evaluates the untrained base model on the selection set: 48 read tasks and 16 edit tasks. The first three arms ran prompt v2 on selection-v2; the RLM arm ran the edit tasks twice, which also measured what an edit episode costs. The production set-up arm then ran Rishi's choices (prompt v3: tool-call code runs and edits get 30 turns; root thinking medium) on selection-v3, where 8 held-out tasks from the trained families replace the ticket tasks. Infra episodes (rate limits, sandboxes, graders) are flagged and run again, never scored as failures.

Edit tiers · spec §12.9

Editing

Edit real is 10 held-out repository tasks (Python 3, Go 4, JavaScript 3); edit synth is 6 generated Python tasks. Edit episodes get 20 turns, 30 sub-calls, 4,096 tokens a turn and the seven coding tools. The repositories themselves are never named here.

Estimates at W&B's prices ($0.40 per million input tokens, $3.00 per million output); W&B's billing page is the truth. Times include waiting for the limiter and the pacing of requests.

Infra · rate limiting

Requests, retries and lost episodes

All arms share one limiter: at most 12 requests in flight to the base model, started at least 0.25 s apart, each retried up to 8 times from 4 s. An infra episode is run again at the end, so it costs time and some money, never accuracy.
